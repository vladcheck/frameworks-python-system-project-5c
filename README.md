# Система учета концертных выступлений

Консольное приложение для учета концертных выступлений: регистрация концертов,
исполнителей, площадок и концертных программ, контроль доступности площадок
и статистика мероприятий.

## Назначение

Приложение для учета концертных выступлений: регистрация концертов, исполнителей,
площадок и концертных программ, а также контроль основных параметров предстоящих
мероприятий (дата, вместимость площадки, цена билета, возрастное ограничение).

## Целевая аудитория

- Организаторы концертов и концертные директора;
- администраторы концертных площадок;
- зрители, интересующиеся афишей выступлений.

## Предметная область

Предметной областью являются концертные мероприятия. Каждый концерт проходит
на определенной площадке, в нем участвует один или несколько исполнителей,
а содержание выступления определяется концертной программой. Система учитывает
даты концертов, вместимость площадок, рейтинги исполнителей и параметры
программ (продолжительность, возрастное ограничение).

## Основные сущности

- Исполнитель — имя, жанр, рейтинг популярности;
- Концерт — название, дата, исполнитель, площадка, программа, ожидаемое число
  зрителей, базовая цена билета;
- Площадка — название, город, вместимость;
- Программа — название, продолжительность, возрастное ограничение.

## Основные функции

- просмотр и поиск концертов по названию;
- просмотр, поиск и отбор площадок по вместимости;
- проверка доступности площадки на дату;
- добавление и отмена концертов (с проверкой занятости площадки и вместимости);
- статистика: число запланированных и прошедших концертов, ожидаемые зрители;
- расчет цены билета по рейтингу исполнителя (функции начального сценария ПР1).

## Структура проекта

- `main.py` — точка запуска и меню приложения;
- `concerts.py` — работа с концертами (включая функции из ПР1);
- `performers.py` — работа с исполнителями;
- `venues.py` — работа с площадками;
- `programs.py` — работа с программами;
- `storage.py` — сохранение и загрузка данных (JSON, контекстные менеджеры);
- `utils.py` — безопасный ввод чисел и дат;
- `data/` — JSON-файлы данных (performers, venues, programs, concerts);
- `tests/` — автоматизированные тесты pytest;
- `tools/` — вспомогательные скрипты (извлечение текста из PDF).

## Формат данных

Данные хранятся в каталоге `data/` в формате JSON — списки словарей.
Концерт ссылается на исполнителя, площадку и программу по идентификаторам.
Даты хранятся в формате ISO (`ГГГГ-ММ-ДД`).
