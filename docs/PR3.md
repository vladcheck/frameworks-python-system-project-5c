## 3. Доработка индивидуального проекта

Название проекта: «Система учета концертных выступлений» — консольное
приложение для учета концертов, исполнителей, площадок и концертных программ.

Основные классы, добавленные на ПР3 (пакет `src/models`):

- `Performer` — исполнитель (`id`, `name`, `genre`, `rating`);
- `Venue` — площадка (`id`, `name`, `city`, `capacity`; методы `is_suitable_for()`,
  `validate_capacity()` — `@staticmethod`);
- `Program` — концертная программа (`id`, `name`, `duration`, `age_limit`;
  метод `is_allowed_for()`);
- `Concert` — концерт, связывает объекты `Performer`, `Venue` и `Program`
  (методы `get_status()`, `calculate_ticket_price()`, `check_venue_fit()`,
  `calculate_revenue()`, `cancel()`, `blocks_venue()`).

У всех классов реализованы конструктор `__init__()`, строковое представление
`__str__()` и методы класса `from_data()` / `to_data()` (преобразование JSON).

Краткое описание доработки: функциональная модель ПР2, в которой сущности
представлялись словарями и списками, переработана в объектную модель:
сущности стали классами, данные — атрибутами объектов, операции, относящиеся
к конкретному объекту, — методами. Концерт хранит ссылки на связанные объекты
(исполнителя, площадку, программу), а не только их идентификаторы; отмена
концерта меняет состояние объекта (`cancel()`), не удаляя его из коллекции.
JSON остался форматом хранения: при загрузке идентификаторы разрешаются в
ссылки на объекты, при сохранении — обратно. Функции обработки коллекций
сохранены как обычные функции модулей пакета `models`. Код перенесен в пакет
`src`, добавлены эталонные копии данных для восстановления (`data/originals/`),
тесты адаптированы к объектной модели (25 тестов проходят), код проверен
flake8, README.md обновлен. Результат зафиксирован в Git коммитами с меткой
«ПР3».

Ссылка на Git-репозиторий: <https://github.com/vladcheck/frameworks-python-system-project-3c>

## 4. Результат работы

В результате выполнения ПР3:

- основные сущности проекта представлены классами и объектами;

## 5. Вывод

В ходе практической работы изучены классы и объекты в Python, атрибуты и
методы, принципы ООП (инкапсуляция, наследование, полиморфизм), а также
декораторы и декораторы методов класса. Индивидуальный проект переработан из
функциональной модели ПР2 в полноценную объектную модель при сохранении всей
функциональности, работы с JSON, тестов и контроля качества кода. Проект готов
к дальнейшему переходу от консольного приложения к веб-приложению на Django.
