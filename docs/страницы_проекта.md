# Страницы проекта

| Страница                      | URL                          | Назначение                                                                                                                 |
| ----------------------------- | ---------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Главная                       | `/`                          | описание приложения, сводная статистика (запланированные / прошедшие / отмененные концерты, ожидаемые зрители) и навигация |
| Список концертов              | `/concerts/`                 | просмотр и поиск концертов по названию, отображение статуса (запланирован / идет / завершен / отменен)                     |
| Страница концерта             | `/concerts/<id>/`            | информация о концерте: исполнитель, площадка, программа, дата, цена билета, ожидаемая выручка, вместимость                 |
| Добавление концерта           | `/concerts/add/`             | форма создания концерта с проверкой занятости площадки на дату и вместимости                                               |
| Отмена концерта               | `/concerts/<id>/cancel/`     | отмена концерта с сохранением объекта в коллекции                                                                          |
| Список исполнителей           | `/performers/`               | отображение исполнителей (имя, жанр, рейтинг)                                                                              |
| Страница исполнителя          | `/performers/<id>/`          | информация об исполнителе и связанных концертах                                                                            |
| Список площадок               | `/venues/`                   | просмотр, поиск и отбор площадок по вместимости                                                                            |
| Страница площадки             | `/venues/<id>/`              | информация о площадке (название, город, вместимость) и её концертах                                                        |
| Проверка доступности площадки | `/venues/<id>/availability/` | проверка доступности площадки на выбранную дату                                                                            |
| Список программ               | `/programs/`                 | отображение концертных программ (название, продолжительность, возрастное ограничение)                                      |
| Страница программы            | `/programs/<id>/`            | информация о программе и связанных концертах                                                                               |
| Статистика                    | `/stats/`                    | число запланированных, прошедших и отмененных концертов, ожидаемые зрители                                                 |
